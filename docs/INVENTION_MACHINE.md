# Invention Machine

## Outcome
Turn a business objective or idea into a researched, visually approved and actionable invention plan with a measurable finish line.

## Flow
Discover opportunities and existing comparable solutions → qualify demand and constraints → propose differentiated concepts → validate assumptions and budget → generate brand, business plan and visual concepts → owner reviews and approves exact artifact versions → hand approved specifications to the existing verified engineering execution path → independent validation → Finished deliverables.

## Shared capabilities
Eden Core for reasoning and context; OpenAI for chat, vision and images; Adobe for documents and creative refinement; Figma for editable design; Google Workspace for research, files, tasks and plans; existing Foreman only after repo admission and a durable worker receipt. No new factory or automatic publication. Distinguish evidence from assumptions, estimates from actual costs and designs from working implementations.

## Acceptance
Real source-backed opportunity brief; one generated and approved versioned design/plan; explicit scope, acceptance tests, cost and rollback; actual engineering handoff receipt if building is requested; independent Guardian on release-critical work. Preserve the approved existing Avatar frontend.
