# Release gates

1. Provenance: new root history, clean dependency graph, approved design assets, no prohibited legacy imports or secrets. Review direct and transitive lockfile dependencies and source references.
2. Identity/data: real Neon login/logout/reload, membership checks, revoked session denial and foreign tenant isolation; migration and rollback test; Core memory ownership and atomic receipt gates.
3. Workspace: actual Google user consent, read and permitted write receipts for each exposed operation, revoked-grant and cross-user denial, no unsupported operation shown as available.
4. Lead Finder and Discovery: actual source-cited fresh search results, deduplication, transparent qualification, saved pipeline and permitted export receipts; review-only drafts, suppression, opt-out, wrong-tenant, cost and retry tests. Invention Machine: source-backed business opportunity brief, approved versioned plans/mockups, real verified handoff and delivery when requested.
5. Chat/media/creative: real provider response and recovery receipts, voice choice approval, actual Tavus playback, authorized Twilio test, generated/edited image, Adobe document, exact revision approval and invalidation.
6. Build and delivery: exact source CI, browser/mobile visual fidelity, security and rollback, independent Guardian review and owner production approval. Existing production stays until all required gates pass.

UNKNOWN is not PASS. No release, external messaging, credential changes or paid provider test unless authorized. Keep checkpoint evidence on the existing project board.
